# Welcome to Pensivo

A modern hybrid notes app for developers and writers.

## Quick Start
- `Ctrl+N` New note
- `Ctrl+O` Open file
- `Ctrl+S` Save
- `Ctrl+W` Close tab

Capabilities

Everything You Need

Nothing you don't.

Tabbed Workspace

Multiple documents open simultaneously. Switch, reorder, and close from the keyboard. Each tab tracks its own file path, language, and dirty state.

Syntax Highlighting

JavaScript, TypeScript, Python, HTML, CSS, JSON, Markdown, YAML, XML, CSV — auto-detected from file extension.

Live Markdown Preview

Write in Markdown, press Ctrl+Shift+P, and watch it render. Full GFM support — tables, code blocks, task lists, blockquotes.

Formatting Toolbar

Bold, italic, strikethrough, headings, lists, code blocks, and hyperlinks — all with proper Markdown syntax insertion.

File Management

Open files via native OS dialog or drag-and-drop. Save with Ctrl+S, Save As with Ctrl+Shift+S. Drop files from Explorer directly onto the app.

Session Persistence

Every tab and every keystroke auto-saves to disk every 2 seconds. Close Pensivo, reopen it — everything is right where you left it.

Philosophy

Built Different

01

Dark-First

142 CSS properties authored on a #0a0a0f canvas. Every pixel — gradients, borders, shadows — designed for darkness.

02

Relentlessly Fast

CodeMirror 6 at 60fps. Cold start under 400ms. No splash screen. No "loading workspace." No excuses.

03

Radically Private

Zero network requests. No accounts. No cloud. No analytics. Your notes are JSON files in a folder you control.

04

Deliberately Minimal

No kanban. No graph view. No plugin store. Just a tabbed editor, syntax highlighting, and live preview — perfected.
