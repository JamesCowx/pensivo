Pensivo

A modern, beautiful notes app for developers and writers. Tabbed editing, syntax highlighting, live Markdown preview, and session persistence — all wrapped in a premium dark UI.

Download for Windows View on GitHub

Tabbed Interface

Work with multiple notes simultaneously. Tabs behave like a modern code editor — drag, close, and reorder with ease.

Syntax Highlighting

Built-in highlighting for JavaScript, Python, HTML, CSS, JSON, and Markdown. Language detection from file extension.

Markdown Preview

Toggle between editing and a live rendered preview. Perfect for writing documentation, notes, or articles.

Rich Formatting

A formatting toolbar helps insert bold, italic, headings, lists, code blocks, and links with proper Markdown syntax.

File Management

Open existing files via native dialog or drag-and-drop. Save with Ctrl+S; auto-detects language from the file extension.

Session Persistence

Tabs and content are auto-saved to disk every 2 seconds. Close and reopen Pensivo — everything is right where you left it.
