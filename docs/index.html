# Welcome to Pensivo

A modern hybrid notes app for developers and writers.

## Quick Start
- `Ctrl+N` New note
- `Ctrl+O` Open file
- `Ctrl+S` Save
- `Ctrl+W` Close tab

> "The palest ink is better than the best memory."

Everything You Need

Nothing you don't.

Tabbed Workspace

Multiple documents open simultaneously. Switch, reorder, and close from the keyboard. Each tab tracks its own file path, language, and dirty state.

Syntax Highlighting

JavaScript, TypeScript, Python, HTML, CSS, JSON, Markdown, YAML, XML, CSV — auto-detected from file extension, manually overridable.

Live Markdown Preview

Write in Markdown, press Ctrl+Shift+P, and watch it render. Full GFM support — tables, code blocks, task lists, blockquotes.

Formatting Toolbar

Bold, italic, strikethrough, headings, bullet lists, numbered lists, code blocks, and hyperlinks — all with proper Markdown syntax insertion.

File Management

Open files via native OS dialog or drag-and-drop from Explorer. Save with Ctrl+S, Save As with Ctrl+Shift+S.

Session Persistence

Every tab and every keystroke auto-saves to disk every 2 seconds. Close Pensivo, reopen it — everything is exactly where you left it.

Built Different

01

Dark-First

142 CSS custom properties authored on a #0a0a0f canvas. Every pixel was designed for darkness. Not an afterthought. Not a toggle.

02

Relentlessly Fast

CodeMirror 6 at 60fps. Cold start under 400ms. No splash screen, no "loading workspace," no excuses.

03

Radically Private

Zero network requests. No accounts. No cloud. No telemetry. Your notes are two JSON files in a folder you control.

04

Deliberately Minimal

No kanban boards. No graph views. No plugin marketplace. Just a tabbed editor, syntax highlighting, and live preview — perfected.
